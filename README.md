# AI Event Framework - Learn by Doing

**Transform real-world challenges into hands-on AI learning experiences**

This framework enables educational institutions and enterprises to create applied AI learning events that connect students with real organizational challenges. Participants develop AI skills by building open-source prototypes that address authentic problems.

## Key Benefits

**For Organizations:**

- Problems identified and scoped at no cost
- Low-resource prototype development
- Access to innovative student solutions

**For Participants:**

- Hands-on AI skill development
- Real-world problem-solving experience
- Interdisciplinary team collaboration
- Certificate of completion
- GitHub portfolio contribution

## Event Formats

- **1-day workshops** - Rapid prototyping sessions
- **3-day hackathons** - Intensive development sprints
- **5-day camps** - Comprehensive skill building
- **12-week courses** - Deep integration with curriculum
